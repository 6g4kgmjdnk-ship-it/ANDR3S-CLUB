# Andr4sClub — Catálogo web

## Cómo agregar un producto nuevo
1. Sube la foto del producto a la carpeta `img/` (ej. `producto-4.jpg`)
2. Abre `products.json` y copia un bloque `{ ... }` existente
3. Cambia `id`, `nombre`, `categoria`, `precio`, `tallas`, `imagen` y `descripcion`
4. Guarda y sube los cambios a GitHub (ver pasos abajo)

## Cómo cambiar tu número de WhatsApp
Abre `script.js` y edita la primera línea:
```
const NUMERO_WHATSAPP = "57XXXXXXXXXX";
```
Usa tu número con indicativo de país (57 para Colombia), sin espacios ni el símbolo +.

## Cómo subir cambios a GitHub (desde el navegador, sin instalar nada)
1. Entra a tu repositorio en github.com
2. Abre el archivo que quieres cambiar (ej. `products.json`)
3. Click en el ícono de lápiz (Edit)
4. Haz tu cambio
5. Baja y click en "Commit changes"
6. Espera 1-2 minutos y refresca tu URL de GitHub Pages
